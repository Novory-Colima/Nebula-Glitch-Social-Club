# Nebula Glitch Social Club

> Premium Specialty Coffee House · Immersive Brand Experience · Astro Showcase

## Visión

Nebula Glitch Social Club es una **cafetería premium de especialidad** creada como una marca ficticia para demostrar el máximo nivel de Frontend Engineering, Motion Design y UX.

Nebula **no es un club gamer**, ni un cibercafé, ni una demo tecnológica.

Es una cafetería de especialidad donde el café es el protagonista y la tecnología únicamente amplifica la experiencia.

La sensación buscada es la de entrar a un espacio exclusivo donde conviven café, diseño contemporáneo, iluminación cinematográfica y gaming cuidadosamente integrado.

El usuario debe salir pensando:

> "Quiero visitar un lugar así."

y no solamente:

> "Qué buena animación."

---

# Dirección visual

Cada sección debe tener al menos una imagen de gran formato.

Nunca construir secciones únicamente con texto.

El café debe aparecer constantemente durante todo el recorrido.

---

# Motion

Las animaciones deben reforzar la atmósfera.

Nunca ser el protagonista.

El usuario debe recordar el lugar.

No las animaciones.

El proyecto fracasa si parece:

- plantilla Tailwind
- landing SaaS
