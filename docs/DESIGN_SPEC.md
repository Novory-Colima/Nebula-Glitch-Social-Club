# DESIGN SPECIFICATION

## Nebula Glitch Social Club

> Creative Direction • Motion Design • Experience Design • Visual Language

---

# Filosofía General

Nebula Glitch Social Club no debe sentirse como una página web.

Debe sentirse como una experiencia digital.

El usuario no navega entre secciones.

El usuario explora un lugar.

Cada scroll representa un recorrido.

Cada transición representa un cambio de ambiente.

Cada interacción debe reforzar la inmersión.

La página debe sorprender constantemente sin resultar agotadora.

---

# Objetivo Emocional

Cuando el usuario visite la página deberá pensar:

"¿Cómo demonios hicieron esto?"

No buscamos únicamente una interfaz bonita.

Buscamos generar asombro.

# Gradientes

Toda la iluminación debe construirse mediante gradientes.

Nunca mediante colores planos.

Ejemplos:

- Indigo → Violeta
- Azul eléctrico → Morado
- Morado → Transparente
- Dorado → Transparente

---

# Iluminación

La iluminación representa uno de los elementos más importantes.

Debe existir iluminación ambiental.

Glow.

Reflejos.

Difusión.

Luz volumétrica.

Jamás sombras duras.

Jamás neones exagerados.

Todo debe sentirse físico.

# Espaciado

El proyecto debe respirar.

Las secciones serán grandes.

Mucho aire.

Mucha profundidad.

No construir bloques comprimidos.

---

# Grid

La composición nunca debe sentirse perfectamente simétrica.

Debe existir tensión visual.

Algunas imágenes deberán romper ligeramente la cuadrícula.

El contenido puede superponerse cuando aporte dinamismo.

---

# Motion Design

El movimiento constituye el ADN del proyecto.

Todo elemento importante deberá poseer comportamiento.

Pero jamás deberán moverse demasiadas cosas simultáneamente.

La atención debe dirigirse cuidadosamente.

---

# Principios de Animación

Toda animación debe responder a una intención.

No animar por animar.

Cada movimiento comunica.

---

## Duraciones

Microinteracciones

120ms–250ms

---

Hover

250ms–450ms

---

Entrada de componentes

600ms–1000ms

---

Transiciones importantes

1000ms–1800ms

---

Nunca superar los 2 segundos.

---

# Easings

Preferentemente:

power2.out

power3.out

expo.out

Nunca:

bounce

elastic

back exagerado

---

# Scroll

El scroll representa el hilo conductor.

Debe sentirse extremadamente fluido.

Cada sección aparece como consecuencia natural del recorrido.

Nunca como bloques independientes.

---

# Parallax

Permitido.

Pero extremadamente sutil.

Máximo:

10%–20%

Nunca convertir la página en una demo de Parallax.

---

# Partículas

Nebula tendrá partículas.

No decorativas.

Atmosféricas.

Muy pocas.

Movimiento lento.

Profundidad.

Nunca lluvia de partículas.

Nunca fuegos artificiales.

---

# Background Animado

El fondo nunca permanecerá completamente estático.

Debe existir movimiento casi imperceptible.

Ejemplos:

Nebulosas.

Gradientes vivos.

Ruido.

Light leaks.

Auroras.

Todo extremadamente lento.

---

# Microinteracciones

Todos los elementos interactivos deberán responder.

Botones.

Cards.

Links.

Inputs.

Iconos.

Nunca existirán elementos "muertos".

---

# Hover

Los hover deben sentirse premium.

Nunca:

scale(1.2)

Nunca:

rotaciones absurdas.

Nunca:

rebotes.

Preferir:

Glow.

Ligera elevación.

Cambio de iluminación.

Blur.

Pequeño desplazamiento.

---

# Hero

Debe provocar el mayor impacto del sitio.

No utilizar carruseles automáticos.

No utilizar sliders tradicionales.

Debe parecer el inicio de una película.

Permitido:

Video.

Canvas.

Shaders.

Partículas.

Capas.

Glass.

Gradientes.

Texto enorme.

Movimiento de cámara.

---

# Storytelling

La Home contará una historia.

Cada sección representa una sala distinta del Social Club.

El usuario avanza físicamente.

No simplemente hace scroll.

---

# Sonido Visual

Aunque la página no tenga audio.

Debe sentirse como si pudiera escucharse.

La iluminación.

Los movimientos.

Las partículas.

Todo debe sugerir ambiente.

---

# Performance

Toda decisión visual debe justificarse.

Si una animación reduce significativamente el rendimiento.

Debe eliminarse.

Nunca sacrificar FPS por espectáculo.

Objetivo:

60 FPS constantes.

---

# Accesibilidad

Las animaciones deberán respetar:

prefers-reduced-motion

Los contrastes deberán cumplir WCAG.

La navegación por teclado será perfecta.

---

# Responsive

No adaptar simplemente.

Rediseñar.

La experiencia móvil deberá sentirse igualmente espectacular.

Nunca esconder componentes únicamente por comodidad.

---

# Objetivo Final

Cuando alguien vea Nebula Glitch Social Club deberá pensar que fue desarrollado por un estudio especializado en experiencias digitales premium.

No debe parecer el trabajo de una sola persona.

Debe parecer el resultado de un equipo formado por:

- Director de Arte
- Motion Designer
- Frontend Engineer
- UX Designer
- Creative Developer

---

# Regla Suprema

Si durante el desarrollo existe un conflicto entre:

- espectacularidad
- rendimiento

Siempre deberá elegirse la solución que conserve la mejor experiencia de usuario.

El lujo digital no consiste en hacer más.

Consiste en hacer exactamente lo necesario de la mejor manera posible.

---

> "No diseñamos interfaces. Diseñamos recuerdos."
