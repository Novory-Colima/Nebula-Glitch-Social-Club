# Nebula Glitch Social Club

> Immersive Gaming Lounge Showcase built with Astro.

---

# Overview

Nebula Glitch Social Club es una marca ficticia creada exclusivamente como proyecto demostrativo para el portafolio de una agencia especializada en desarrollo web, experiencia de usuario, motion design y experiencias digitales inmersivas.

Este proyecto *no representa una cafetería real*, ni pretende funcionar como un sitio comercial.

Su único propósito consiste en demostrar el máximo nivel técnico, visual y creativo que la agencia es capaz de desarrollar utilizando tecnologías Frontend modernas.

Nebula debe sentirse como una experiencia interactiva antes que como una simple página web.

Cada interacción, cada transición, cada animación y cada elemento visual deben contribuir a construir una atmósfera futurista, cinematográfica y memorable.

El objetivo no consiste únicamente en impresionar mediante efectos visuales, sino en demostrar dominio de arquitectura Frontend, rendimiento, UX y Motion Design de alto nivel.

# Concepto

Nebula Glitch Social Club no es simplemente una cafetería.

Es un punto de encuentro donde gastronomía, videojuegos, tecnología y ciencia ficción convergen dentro de una experiencia cuidadosamente diseñada.

La página debe transmitir la sensación de ingresar a una estación espacial destinada al entretenimiento.

No queremos que el usuario vea una web.

Queremos que sienta que acaba de entrar en un lugar.

---

# Filosofía del Proyecto

Todo el proyecto gira alrededor de una sola idea:

*La inmersión.*

Cada decisión deberá reforzar esa sensación.

Las animaciones no existen para decorar.

Existen para construir atmósfera.

El usuario nunca debe sentir que está navegando entre secciones independientes.

Todo debe sentirse como un único recorrido continuo.

---

# Principios Fundamentales

## Experiencia primero

La experiencia completa tiene prioridad sobre cualquier componente individual.

Cada elemento debe aportar al recorrido.

Nada debe sentirse aislado.

---

## Motion como lenguaje

Las animaciones forman parte de la interfaz.

No son efectos añadidos.

El movimiento comunica jerarquía.

Comunica profundidad.

Comunica espacio.

Comunica intención.

---

## Inmersión constante

El usuario nunca debe salir del universo visual del sitio.

Los cambios de sección deben sentirse naturales.

La iluminación.

Las partículas.

La profundidad.

Los efectos de luz.

Todo debe mantener una identidad coherente.

---

## Calidad antes que cantidad

Es preferible construir pocas secciones absolutamente espectaculares que muchas secciones genéricas.

Cada componente debe sentirse terminado.

Nunca provisional.

---

## Rendimiento

La experiencia debe sentirse extremadamente fluida.

Las animaciones jamás deberán comprometer el rendimiento.

Toda decisión visual deberá justificarse técnicamente.

---

# Responsive

- Tablet
- Laptop

- UltraWide

# Arquitectura

Toda la aplicación deberá construirse mediante componentes pequeños, reutilizables y desacoplados.

Cada componente tendrá una única responsabilidad.

La lógica deberá permanecer separada de la presentación.

Las animaciones deberán vivir en módulos independientes.

El código deberá ser fácil de extender hacia futuras secciones o nuevas experiencias.

---

# Filosofía de Motion Design

El movimiento constituye la identidad principal del proyecto.

Las animaciones deben sentirse:

- cinematográficas
- inmersivas
- elegantes
- precisas
- fluidas
- naturales

Evitar:

- rebotes exagerados
- movimientos caricaturescos
- easings artificiales
- animaciones largas
- efectos innecesarios

Cada animación debe tener un propósito.

---

# Filosofía de Interacción

La página debe reaccionar constantemente a la presencia del usuario.

Hover.

Scroll.

Cambio de sección.

Entrada de contenido.

Microinteracciones.

Todo debe responder con naturalidad.

La interfaz debe sentirse viva.

Nunca caótica.
